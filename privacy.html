How Orivance Personal Assistant handles information

Orivance Personal Assistant is private-use, self-hosted software. This policy explains the optional Gmail integration and the handling of Google user data.

1. What Google data the app accesses

Only after its owner consents, the application may read Gmail messages and metadata through the Gmail API with https://www.googleapis.com/auth/gmail.readonly. Information may include sender and recipient addresses, subject, message content, timestamps, thread IDs, and message identifiers. Routine message ingestion is designed to avoid downloading attachments.

2. How the data is used

The app reads incoming Gmail messages to identify important correspondence, receipts, renewals, possible bills, and follow-ups; prepare private summaries; and avoid duplicate processing. Email content is treated as untrusted data, not instructions giving the app new permissions.

The Gmail connection does not send or modify email, change labels, archive, delete, mark messages read, make purchases, or execute payments.

3. Storage, security, and retention

Processed message data and synchronization state are stored in the owner's private, self-hosted environment, including a local database and any local backups. Operational access is restricted to authorized owner-controlled systems and channels. OAuth credentials and refresh tokens are not placed on this public website or in its public source repository.

Stored data and backups may remain until the owner deletes them using the private system's data-management procedures. There is no promised automatic deletion schedule.

4. Sharing and external processing

The application does not sell Google user data or use it for advertising or data brokerage. If the owner independently enables private notifications or summaries through iMessage, selected summary content may pass through Apple's messaging infrastructure to the specifically authorized conversation. Merely authorizing Gmail does not enable those notifications.

Where local AI processing is configured, Gmail-derived content is processed in the owner's private self-hosted setup; the app does not send Gmail content to a general-purpose external AI provider to train models.

5. Google API Services User Data Policy

Data obtained through Google APIs is used only for the owner-authorized features described here. It is not used for advertising, unrelated profiling, or training generalized machine-learning or AI models. The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

6. Access, consent, and revocation

The owner can revoke Google's authorization from Google Account connections. Revoking access stops future access through that OAuth grant but does not automatically remove information previously saved locally or in backups. The owner can arrange removal of that local information using private system administration.

Questions about this policy can be directed to the application owner through the contact address displayed on Google's OAuth consent screen.

7. This public website

This website is informational only and does not collect Google email content, host a mailbox, or use advertising or analytics scripts. GitHub Pages hosts this site and may process standard website requests under GitHub's policies.

8. Changes

This page will be updated when data practices materially change.
